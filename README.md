The PNG and MP3 file pair is used to display the animated musical score. The application allows you to compile a table containing the vertical coordinates of each staff line and the corresponding scrolling timings. This table is saved and hidden within the initial bytes of the PNG file. The sequence supports forward and backward jumps for repeats and refrains. PNG files saved in the download folder must be moved to overwrite the original files.
